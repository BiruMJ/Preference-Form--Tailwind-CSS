# Preference Form Page

A clean and user-friendly Preference Form interface built for a subscription-based service (Leaf & Brew Box). This project utilizes Tailwind CSS to create a modern, responsive layout that guides users through selecting their product preferences.

## Screenshot

- [Desktop Screenshot](./Screenshot%20Desktop.png)
- [Mobile Screenshot](./Screenshot%20Mobile.png)

## 🚀 Features

- **Intuitive UI:** Designed to streamline the user experience when setting up subscription preferences.
- **Image Integration:** Fully adaptive design that looks great on mobile, tablet, and desktop screens.
- **Tailwind CSS Integration:** Leverages utility-first CSS for consistent spacing, clean typography, and rapid styling.
- **Interactive Design:** Structurally prepared for forms, toggles, or selection inputs.
